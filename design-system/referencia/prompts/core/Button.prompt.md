The action control — green `primary` by default, gold `accent` for the single hero CTA of a view.

```jsx
<Button icon="plus">Cadastrar fazenda</Button>
<Button variant="secondary" size="sm" icon="download">Exportar</Button>
<Button variant="accent" size="lg">Falar com um corretor</Button>
```

Pill shape. Variants: primary, accent, secondary, soft, dark, ghost, danger. Sizes sm/md/lg = 32/40/48px (lg for mobile primary actions); `count` adds a round counter. Labels are sentence case, verb-first, Portuguese. Never two gold buttons in one view.
