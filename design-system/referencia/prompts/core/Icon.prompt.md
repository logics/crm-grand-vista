Monochrome Lucide glyph inlined as SVG in currentColor, 1.5px stroke — the only icon primitive in the system.

```jsx
<Icon name="map-pin" size={16} />
<Icon name="droplets" size={20} color="var(--gv-info-600)" title="Disponibilidade hídrica" />
```

Never inline hand-drawn SVG. Common Grand Vista glyphs: `tractor`, `wheat`, `droplets`, `map-pin`, `ruler`, `file-text`, `shield-check`, `users`, `calendar-clock`, `trending-up`.
