Shown when a list has no records. Says what is missing and offers the one action that fixes it.

```jsx
<EmptyState icon="tractor" title="Nenhuma fazenda compatível"
  description="Ajuste a faixa de valor ou as regiões de interesse do comprador para ampliar o matching."
  action={<Button variant="secondary" icon="sliders-horizontal">Revisar perfil</Button>} />
```
