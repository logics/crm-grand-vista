Opportunity card inside a pipeline column.

```jsx
<DealCard client="Agro Holding Bertoldi" farm="Fazenda Três Barras" value="R$ 18,4 mi"
  probability={75} owner="MS" nextAction="Visita técnica · 28/07" />
```

Set `overdue` when the próxima atividade is late — that is how "negociações estagnadas" surfaces.
