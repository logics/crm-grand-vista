The default content container: white, no border, 20px radius, very soft shadow on the stone canvas. `tone="hero"` for the one green-gradient card per view.

```jsx
<Card eyebrow="Pipeline" title="Negociações ativas" action={<Button size="sm" variant="secondary">Ver todas</Button>}>
  …
</Card>
```

`accent` adds a thin gold inner ring (priority / destaque only). `interactive` for clickable cards.
