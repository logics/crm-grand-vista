Square icon-only control for table rows, toolbars and card corners.

```jsx
<IconButton icon="pencil" label="Editar" />
<IconButton icon="more-vertical" label="Mais ações" size="sm" />
<IconButton icon="whatsapp" label="Enviar oportunidade" variant="solid" />
```

`label` is mandatory. Default `ghost` in dense UI; `outline` when it sits alone.
